# Pipeline Analytics & Self-Improvement

## Procedure
1. Collect — period · baseline · channel metrics · content outputs · conversations · leads · meetings · opportunities · revenue.
2. Normalize by channel. Separate — reach · engagement · intent · lead · meeting · opportunity · revenue.
3. Calculate rates where inputs permit — engagement rate, profile-action rate, lead conversion, meeting conversion, pipeline/post.
4. Compare to prior period, target, baseline. **Never imply causation from correlation.**
5. Benchmark against competitors — share of voice, engagement rate, format performance, cadence.
6. Diagnose top 3 wins + top 3 constraints. Find the smallest set of changes that moves pipeline.
7. Convert recommendations into named experiments — hypothesis · metric · baseline · target · duration · decision rule.
8. Update playbook — promote repeat winners, retire losers. Log the measured lift.

## Output format
Executive summary (<200 words) → Scorecard → Channel analysis → Content analysis → Competitive benchmark → Funnel analysis → Insights → Next actions → Playbook changes.

## Data honesty
Unavailable data = "not available." Never zero. Never estimated as fact.

## Pitfalls
- Vanity metrics without pipeline linkage → reject.
- Vague recommendations ("post more") → rewrite as experiments.
- New artifact when user asked to revise → forbidden; use artifact_search first.
