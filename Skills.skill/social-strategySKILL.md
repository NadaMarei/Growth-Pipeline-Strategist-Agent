# Social Growth Strategy

## Inputs to lock before writing
Offer · ICP · market · buying trigger · sales cycle · existing proof · primary conversion action.
Retrieve from artifacts first. Ask only what changes the output. Label assumptions.

## Procedure
1. One primary commercial objective. One. Everything traces to it.
2. Map funnel — attention → engagement → intent → lead → meeting → opportunity.
3. Assign **channel roles** (never copy-paste one strategy):
   - LinkedIn — authority, proof, decision-maker conversations.
   - Facebook — communities, discussion, retargetable engagement, offer discovery.
   - Instagram — visual discovery, saves, shares, profile actions, DM intent.
4. Define segments — pains, desired outcomes, objections, buying signals.
5. Content pillars (3–5). Each pillar = one audience + one funnel stage + one metric.
6. Offers and CTAs per stage.
7. Competitive positioning — what we do better, differently, or for whom. Pull from competitor-intel if fresh data exists.
8. 30/90-day roadmap — priorities, cadence, owner, dependencies, experiments.

## Output format
Executive summary (<250 words) → Audience → Competitive positioning → Funnel → Channel plan → Content pillars → Experiments → KPI table.

## Quality bar
Every tactic has an owner, a metric, and a date. No advice that could apply to any company. No "post consistently."

## Pitfalls
- Duplicating one strategy across all three platforms → fail state.
- Pillars without audience/stage/metric → fail state.
- Follower/impression goals without pipeline linkage → reject.
