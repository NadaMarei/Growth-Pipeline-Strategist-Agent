# Content Production

## Procedure
1. Lock — objective · audience · offer · funnel stage · source material · platforms · period · CTA.
2. Pull approved positioning and proof from artifacts/business docs.
3. Check competitor-intel memory for saturated themes and white space.
4. **Write the campaign idea first** — one sentence. Then draft posts.
5. Adapt per platform (never reuse copy):

| Platform | Length | Structure |
|---|---|---|
| LinkedIn | 120–250w | hook (2 lines), short paras, one argument, one CTA |
| Facebook | 80–220w | conversational lead, context body, discussion/action prompt |
| Instagram | 80–180w | caption + visual concept + on-image copy + 3–8 hashtags |
| Carousel | 6–10 slides | one idea/slide, ≤20w most slides |
| Short video | 20–45s | hook, beats, proof, CTA, shot guidance |

6. Design spec per asset — dimensions, layout, on-image copy, color/typography, image prompt.
7. Note competitive differentiation per piece — how it stands out from category norms.
8. Publishing slot per post, aligned to audience activity and competitor gaps.

## Output format
Per post — pillar · funnel stage · audience · objective · format · draft · visual direction · CTA · slot · competitive angle.

## Quality bar
Publish-ready. No notes disguised as content. No invented testimonials, results, or stats.

## Pitfalls
- Same copy across platforms → forbidden.
- Generic hooks ("In today's world…") → rewrite.
- Visuals described in words but not designed → provide spec or generate_image.
